#### 計画E：論文1で θ がばらつく仕組みを、文面から探す（課題17）

- **改善したいこと：** 論文1では、速度一致で全員の向き θ が完全にそろい（φ=1.00）、整列度が扇の広さだけで決まってしまう。そのため α=0.3〜0.4 の急な落ち方が出ず、α=0.3 の整列度も低い（4.3・4.8 節）。
- **効くと考えていること：** 式(4)〜(8) を読み直すと、実装と文面がずれていそうな箇所がまだ2つある。どちらも、前向きの遷移先が選ばれやすくなる偏りを減らし、θ にばらつきが入る方向に効くと考えた。
  - **E1 同率の最大人気サイトの選び方。** 式(4) の下に「最大人気のサイトが複数あれば、そのうち1つをランダムに選ぶ」とある。v1 は、同率の遷移（本数）の中からランダムに選んでいるので、同じサイトを指す遷移が多いサイトほど選ばれやすい。短い遷移は同じサイトに重なりやすく、扇の真ん中（前向き）に集まる。**サイト単位で一様に選ぶ**ように変えてみる。
  - **E2 速度一致で平均するもの。** 式(8) の説明は「近傍 M の平均の速度の向き」。これまでに「近傍の実際の移動の向き（単位ベクトル）の平均」は試した（4.3 節、φ は 0.97 以上のまま）。今回は、**移動ベクトルそのもの（長さも含む、留まった個体は 0）の和の向き**を試す。長い移動ほど重みが大きくなるので、扇の端への長い移動が θ を揺らす可能性がある。
- **どう試すか：** E1・E2 をそれぞれ1つずつ、また両方を入れた版で、α=0.2〜0.7、P=10 / 15 / 20、5シード、900 ステップ（計画2 と同じ測り方）。α の読み方は「そのまま」と「2倍」の両方。φ と整列度・密度・ルールの割合を記録する。
- **成功の目安：** φ が 1 より下がり（θ がばらつき）、整列度の α に対する傾きが急になること。特に、論文の α=0.3 / 0.4 / 0.5 の 0.53 / 0.30 / 0.13 に近づくこと。どれも効かなければ、「論文1の文面からは θ のばらつきは生まれない」と記録し、先生に確認したいことに足す。
- E1・E2 は、v1 に元の挙動へ戻せるオプションとして足す（CLAUDE.md の決まりどおり）。
- **結果（11/21、03_論文1.md の 4.10 節）：終わった。**
  - E1（`choose_by="site"`）は効かない（整列度の変化 0.03 以内、φ も 1.00 のまま）。
  - E2（`vm_source="disp"`）は、round と組むと θ がばらつくようになった（α そのまま・round で φ 0.94→0.53、2倍・round で 0.86→0.29）。論文1で θ がばらつく仕組みが初めて見つかった。
  - α そのまま・round ＋ E2 で、α=0.3 / 0.4 / 0.5 / 0.6 の整列度は 0.51 / 0.43 / 0.34 / 0.25（論文 0.53 / 0.30 / 0.13 / 0.10）。α=0.3 は合うが、α が大きい側は高すぎる。2倍・round ＋ E2 は全体に低すぎる（0.25 / 0.11 / 0.06 / 0.05）。論文の値は2つの間にある。

#### 計画I：スケールフリー相関（論文1の図15）を確かめる（課題28）

- **改善したいこと：** 論文1の図15d では、相関関数 C を「相関長 ξ で割った距離 r/ξ」に対して描くと、全スナップショットが1本の直線に乗る（r/ξ=0 で約 1.05、r/ξ=1.3 で約 −0.2、傾きは約 −1）。実際のカニ（図15c）も同じ傾き（約 −0.9）で、ムクドリの群れ（Cavagna et al. 2010）とも同じだと書かれている。前にノートブック（`MAM_valid.ipynb` の「スケールフリー相関」）で試したときは、傾きが論文と違っていた。ただし、そのときの値は記録に残っていない。
- **論文の定義（p.22）：**
  - 揺らぎベクトル u_i = v_i − (全員の速度の平均)。v_i は i 番目の個体の速度（スナップショットの移動）。
  - C(r) = Σ u_i·u_j δ(r − r_ij) / Σ δ(r − r_ij)。相関長 ξ は C(r)=0 になる距離。
  - 図15 の条件は L=4、R(Nf)=2、**R(M)=2**（他の図の R(M)=3 と違う）。P と α は書かれていない。
- **効くと考えていること：** ξ を「C が 0 になる距離」で決めるので、どの曲線も r/ξ=1 で 0 を通る。そのため傾きは、ほぼ「r/ξ=0 での C の値（近い個体どうしの相関の強さ）」で決まる。傾きが違うのは、近い個体どうしの速度のそろい方が論文と違うか、速度の取り方（1ステップの移動か、何ステップかの平均か）が違うからだと考えている。前の解析は 20 ステップ分の移動を速度にしていた（tau=20）。
- **どう試すか：**
  1. 今の v1（α そのまま・floor）と、計画2で一番近かった設定（α 2倍・round）で、図15 と同じ R(M)=2 にして回す。P=10〜20、α=0.3〜0.7、5シード。
  2. 速度を1ステップの移動（論文の「スナップショットの移動」）と、3・5・10・20 ステップの移動の平均の両方で取り、C(r)・ξ・r/ξ に対する直線の傾きと切片・R² を求める。
  3. 傾きの α・P・速度の取り方による違いを表にし、論文（約 −1、切片 約 1.05）と比べる。
  4. ノートブックの解析関数（`analyze_scale_free` など）を使い、計算方法が論文の定義と1文ずつ合っているかも確かめる。
- **成功の目安：** 論文と同じ傾き（−0.9〜−1.1）になる条件があるかどうか、ないならどこがずれているかを1文で説明できること。
- 計画E で θ のばらつきが変われば、近い個体どうしの相関も変わるので、計画E の結果が出たら、その設定でも測り直す。
- **結果（11/22、03_論文1.md の 4.13 節）：終わった。論文と同じ傾きになる条件は見つからなかった。**
  - ノートブックと同じ規格化（自分との積で割る）で、傾きは v1 で −0.07（速度1ステップ）〜−0.27（10ステップ）。α 2倍・round でも −0.08〜−0.35。論文は −0.96。
  - 理由（1文）：1ステップの移動は可能的遷移の選び方で個体ごとにばらばらにぶれるので、自分との積だけが大きくなり、近い個体どうしの相関（r/ξ=0 での C）が小さくなる。
  - 速度一致で移動を平均すると（E2）、近い個体どうしの揺らぎがそろって傾きが急になる（α そのまま・round＋E2 で −0.28〜−0.50）。それでも論文の半分。
  - P と α ではほとんど変わらない。R² は 0.4〜0.8 で、論文ほどきれいな直線にならない。
  - 規格化を「割らない」にすると E2 の設定で論文に近い値になるが、単位で値が変わるので根拠にならない。論文の規格化と速度の取り方を先生に確認する（確認したいこと 9）。

#### 計画F：密度の谷を、シードを増やして確かめる（課題18）

- **改善したいこと：** 論文の図11 では、P=8〜12 で密度がいったん下がる（谷）。計画B で区画 2×2（Ls=25）で測ると、α=0.6 の P=12 に谷らしきものが出たが、3シードだけで、α=0.3 では出なかった（4.9 節）。
- **効くと考えていること：** 谷が本物なら、シードを増やしても同じ P に残るはず。偶然なら、平均すると消える。
- **どう試すか：** 計画B と同じ設定（v1 と α 2倍・round）で、P=4〜20 を 1 刻み、α=0.3〜0.6、10シードにして、区画 2×2 の密度を測る。谷があれば、そのときの群れの形（回転半径、スナップショット）を見る。
- **成功の目安：** 谷が出るか出ないかを、誤差の幅つきで言えること。
- **結果（11/21、03_論文1.md の 4.11 節）：終わった。** 谷が出たのは α 2倍・round の α=0.6 だけで、P=11〜15 で約 0.1 下がる（標準誤差の約3倍）。論文の位置（P=8〜12）より少しずれる。v1 の全 α と、2倍・round の α=0.3〜0.5 では出ない。E2 でも確かめる必要がある。

#### 計画G：論文1で相互予期が多すぎるかを調べる（課題20・19）

- **改善したいこと：** 今の論文1のモデルでは、相互予期が 99% で、追従と自由移動がほとんど起きない。図13・14 の密度を Ls=10 で読むと、群れが論文より詰まりすぎていることになる（4.9 節）。
- **効くと考えていること：** 相互予期の割合は、人気度の閾値（式(4) の ζ≥2）と、同率・競合の扱いで決まる。計画E の E1 や、文字どおりの競合（4.6 節）で相互予期が減ると、群れがゆるくなり、密度が下がるはず。
- **どう試すか：** 計画E の結果を使い、各版のルールの割合と、区画 Ls=10 / Ls=25 の密度を並べる。論文1にルールの割合を示す図はないので、論文2の図S2 の値（赤・緑で相互予期 約 98〜99%）も参考に、99% がおかしいかどうかを考える。
- **成功の目安：** 「論文1でも相互予期 99% でよいのか」について、根拠をつけて答えられること。決まらなければ、先生に確認したいことに足す。
- **結果（11/22、03_論文1.md の 4.14 節）：終わった。99% でよい（課題20 は問題ではない）。**
  - 相互予期の割合は P で決まり、P≥10 で 98〜99%。v1・α 2倍・E2 のどれでもほぼ同じ。式(4) の決まりから自然に出る値で、論文2の図S2（P=40 で 98〜99%）とも合う。
  - E2 は相互予期がほぼ同じなのに密度が低い。群れの詰まりすぎは、相互予期の割合ではなく速度一致の読み方（確認したいこと 8）で決まる。
  - 文字どおりの競合だけ、相互予期が 45〜67% になる（負けた個体が追従・自由移動に回るため）。

#### 計画H：論文2の図S3 の ω≤1 を、ω の2つの読み方で調べておく（課題6）

- **改善したいこと：** 論文の図S3 では ω≤1 で整列度が低いが、モデルではどの設定でも ω=1 で 0.8〜0.9 になる（3.6 節）。ω=1 では、式どおりと説明文どおりの2つの読み方が同じ式になるので、ω の読み方では説明できない。
- **効くと考えていること：** ω=1 では、直前の移動と前の基本ベクトルを同じ重みで足すので、θ は移動のぶれを半分ずつ取り込む。そろうまでの時間や、そろったあとの θ のばらつきが、ω の大きさでどう変わるかを見れば、論文の「ω≤1 で低い」の理由が分かるかもしれない。
- **どう試すか：** α 2倍・round・1個体1票で、ω=0、0.25、0.5、0.75、1、1.5、2 を、ω の2つの読み方それぞれで回す（P=40、α=0.2、5シード、1500 ステップ）。整列度の時系列、θ のそろい φ、そろうまでのステップ数を記録する。
- **成功の目安：** ω≤1 で整列度が下がる条件があるか、ないならその理由を1文で説明できること。先生の答え（ω の読み方）が出たら、すぐ使える形にしておく。
- **結果（11/22、02_論文2.md の 3.11 節）：終わった。**
  - 論文の図S3 を読み直すと、低いのは主に ω=0（0.10）で、ω=1 は 0.70（モデルは両方の読み方で 0.81）と大差ない。
  - 2つの読み方は、ω と 1/ω を入れ替えただけの関係（結果が完全に一致した）。
  - 理由（1文）：ω=0 のとき、式どおりでは θ が直前の移動の向きになって移動を通してそろう（0.65）が、説明文どおりでは θ が最初のランダムな向きのまま変わらない（0.12、論文と合う）。
  - ω≥8 で下がる所は式どおりだけが合う。図S3 全体に合う読み方はない。確認したいこと 2 に足した。
