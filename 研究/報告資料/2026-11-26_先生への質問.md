**論文2 について**

1. 相互予期の更新順を、本文 図2 の流れ図どおりにしてよいでしょうか。（11）
   - α 2倍で全図を作り直すと、形はほぼ合います（図3 の順番、図3a、図S3 の ω=1〜8、2体、図4 の形、図S4 の主な形）。ずれが残るのは、緑の整列度（0.13、論文 0.35）、赤の整列度（0.81、論文 0.93）、青のルールの割合（相互予期 72%、論文 63%）、図4b の旋回の力の幅（0.6、論文 約 2）です。
   - θ の入れ方（式(2) の丸め、ω の掛け方）と、本文 p.4 の遷移の選び方の読み方（競合・人気度の順など）を試しましたが、同時に直る読み方はありませんでした。
   - 流れ図を見ると、相互予期は「人気度が1より大きいサイトがあるか → 一番人気のサイトへ1体が入る」をくり返す、**サイトを中心にしたループ**でした。入る個体は、本文 p.4 のとおり「そのサイトへの向きが基本ベクトルに一番近い個体」にしました。今の実装は「ランダムな順に1体ずつ」の個体中心です。
   - 流れ図どおりにすると、緑の整列度 0.58（論文 0.35）、赤は1つの群れの中が 0.94〜0.95（論文 0.93）になり、図S4（3体）の残差も論文の説明に近づきます。2体は変わりません。
   - ただし、赤で逆向きの群れが合わさらないシードがあり（10本中3本）、平均は 0.68 に下がります。青のルールの割合と図4b の旋回の力の幅は、どちらの更新順でも変わりません。
   - → 流れ図どおりの更新順を採用してよいでしょうか。また、青のルールの割合と旋回の力の幅のずれは、α 2倍に読んだことの代わりに出るものとして受け入れてよいでしょうか（α 1倍ならこの2つは合いますが、図3 の順番と図3a が合わなくなります）。

2. ω の掛け方は、式(13) どおりでよいでしょうか。（9）
   - 式(13)・本文 p.4 と、図S3 の説明文で逆になっています。
   - 2体の結果と図S3 の ω≥8 で下がる所は式どおりで合い、図S3 の ω=0 で低い所だけは説明文どおりでないと出ません。どちらの更新順でも同じです。

**論文1 について**

3. 速度一致（式(8)）で何を平均しているのでしょうか。（4）
   - 式の記号は基本ベクトルの向き θ の平均、言葉の説明は「近傍の平均の速度の向き」です。今は、α を文面どおり読めるように、近傍の実際の移動を平均しています。
   - この版では、P が大きいほど整列度が上がります（P=30・α=0.5 で 0.34、図11 は 0.13）。調べると、動く向きのばらつきは P によらず、群れが密になるほど θ がそろっていました。近傍の移動を平均するので、密になる＝そろう、が結びついています。
   - 文面で分かれる読み方（1体ずつの更新、追従先、R(Nf)、サイト単位の選び方、floor、自分を含めるか、速度一致を相互予期の前にするか）を全部試しても、この結びつきは切れませんでした。
   - → 図11 の「密度 0.8〜0.9 で整列度 0.1 前後」を出すために、論文のコードには式(8) のほかに θ を揺らす処理（ノイズなど）があったのでしょうか。

4. 図10・図11 の密度は、何で割っているのでしょうか。（13）
   - 本文 p.17 は「区画の中の個体数を全個体数で割る」ですが、図10・図11 の密度はどれも横軸 0 でちょうど 1.0 から始まっています。「摂動がないときの最大密度で割る」なら説明できます。
   - 今のモデルで P=1 の密度で割ると、P=30 が 1.2〜2.0 になり合いません。→ 何で割っているか、または初期配置が固まった状態から始めているかを教えてください。

5. 追従者近傍の半径 R(Nf) はどちらが正しいでしょうか。（12）
   - 本文 p.10 は「基本ベクトルの長さより大きい」（L=4 なので 5 以上）、図10・11 などの説明は R(Nf)=2 です。
   - R(Nf)=5 にすると P=2 で群れが崩れる様子が強くなりますが、P≥10 は変わりません。

   - → 著者のコードで、自分のサイトへの遷移はどう扱っていたでしょうか。
