## 2.20 動画から個体の位置を取り出して、モデルと比べる（計画T、11/27）

- **ねらい：** 動画は論文1 の図そのものではないが、論文の著者のコードで回した結果。見た目だけでなく、数値（個体の数、場の大きさ、歩幅、整列度、塊の数）を取り出せれば、今のモデルと何が違うかの手がかりになる。
- **動画：** チャンネル「YukioPegioGunjiLab」の9本（2013年）。本『群れは意識をもつ』の図3-6a,b（速度一致なし）、図3-8（速度一致あり、P=1・2・4・10・15・25）、図3-12（水たまり）。説明文は図3-8 が「速度一致で基本の遷移を合わせてから相互予期する」、図3-6 が「速度の同調なし」。α・L・R(M) などは書かれていない。
- **取り出し方：** ブラウザで動画のフレームを読み、黒い四角（個体）の位置を格子に直した（`report_scripts/planT_video_extract.js`）。
  - 1マスは 2 画素で、個体は 3×3 画素の四角（隣どうしで 1 画素重なる）。場はどの動画も **100×100 マス**。
  - 動画は画面を録画したもので、個体を描き直している途中のフレームが混ざる（25〜30 体ずつ増えていく）。個体の数が一番多いフレームの 97〜103% のものだけを使い、続けて同じフレームを1つにまとめて「1ステップ」とした。
  - 移動は、次のステップの一番近い個体と結んで測った。取り違えを避けるため、歩幅と留まる割合は**ほかの個体から 8 マス以上離れた個体**だけで数えた。塊は、チェビシェフ距離 2 以内でつながる個体のまとまり。
  - 結果：`report_data/planT_video.json`。

### 動画から読み取れた値

| 図3-8 P=2・P=1 | 約 200 | — | — | — | ぼやけていて測れない。P=2 は小さな群れにばらばらに分かれる。P=1 はいくつかの塊（論文の「BOIDS のように全員そろって直進」とは見た目が違う） |

- **条件が論文と違う。** 場は 100×100（論文は 50×50）。個体数は P=10 と P=4 が約 200、P=15・25 が約 410 で、**動画ごとに違う**（論文は N=100）。密度（N/S²）は P=10 で 0.02（論文の半分）、P=15・25 で 0.04（論文と同じ）。
- **歩幅は L=4 と合う。** 離れた個体は1ステップに 0〜4 マス（まれに 5〜7）動き、平均 1.7〜2.2 マス。今のモデル（L=4）でも 2.0〜2.3 マス。
- **整列度はどの P でも低い（0.1〜0.2）。** 速度一致なし（図3-6）でも 0.2 前後。
- **P=10 では、塊が時間とともに合わさって大きくなる**（一番大きい塊 46 → 110 体）。速度一致なし（図3-6）では、すぐに 2〜6 個の密な塊になり、離れた個体がいなくなる。つまり**「密なのにそろわない」状態は、速度一致なしの動画で出ている。**
- **P=10 では、離れた個体の 7〜9% が1ステップの間その場に留まる。** 今のモデルでは 0%（自分のいるサイトは「空いていない」ので、長さ 0 の遷移は選べない）。描き直し途中のフレームのせいで多めに出る可能性はあるが、P=10 の動画はフレームがきれいで、3つの時刻でそろっている。

### 同じ条件でモデルを回して比べる

- 動画と同じ S=100・N=200・P=10 と N=400・P=15 で、今の一番よい版（移動で速度一致）と θ で速度一致する版を回し、同じ量を測った（α=0.3・0.5・0.7、2シード、t=130・680・1220 から 40 ステップずつ）。スクリプト：`report_scripts/planT_video_model.py`。データ：`report_data/planT_video_model.json`。

- **動画の「整列度が低い」と「塊が合わさって大きくなる」を、両方出す版はない。** 移動で速度一致する版は、α=0.5 で整列度は合うが、塊は合わさらずにばらける。θ で速度一致する版は、塊は合わさるが、整列度が 0.4〜0.65 と高すぎる。これは 2.18 節の「密になる＝そろう」の結びつきを、動画の側から見たもの。

### 動画から出た手がかりを、論文1 の条件で試す

論文1 の条件（N=100・S=50・L=4・R(Nf)=2・R(M)=3）で、P=2・10・30 × α=0.3〜0.6 × 3シード、900 ステップ。スクリプト：`report_scripts/planT_leads.py`。データ：`report_data/planT_leads.json`。

- **手がかり1「留まりあり」：** 長さ 0 の遷移（自分のサイト）を、自分にとっては空きとして扱う。式(6) の「どの個体 j にも占められていない」を文字どおりに読むと自分も入るので、文面からは外れる。ただし、自分が動く前に自分の場所を空きとみなすコードは自然に書ける。
- **手がかり2「速度一致なし」：** 論文1 は「Gunji et al. 2012 と Murakami et al. 2017 のモデルは、速度一致がないほかは同じ」と書いている。図11 の説明には L・R(M) が書かれていない（図10 には R(M)=3 がある）。そこで、速度一致なし（論文2 のモデル：θ を自分の移動と ω=5 で更新、α そのまま・round）を論文1 の条件で回した。

**表16** 整列度（α=0.3 / 0.4 / 0.5 / 0.6）と密度（Ls=25、α の平均）、留まる割合

| 読み方 | P=10 | P=30 | 密度 P=10 / 30 | 留まる P=10 / 30 |
|---|---|---|---|---|
| **論文 図11**（P が大きい所） | 0.53 / 0.30 / 0.13 / 0.10 | 同じ | 0.8〜0.9 | — |
| 今の一番よい版 | 0.44 / 0.31 / 0.23 / 0.14 | 0.49 / 0.40 / 0.34 / 0.26 | 0.45 / 0.64 | 0.00 / 0.00 |
| 留まりあり | 0.30 / 0.23 / 0.16 / **0.10** | 0.26 / 0.20 / **0.17 / 0.10** | 0.47 / 0.61 | **0.29 / 0.53** |
| 速度一致なし（論文2 型） | 0.08 / 0.09 / 0.11 / 0.07 | 0.31 / 0.52 / 0.46 / 0.41 | 0.32 / 0.49 | 0.00 / 0.00 |

- **留まりありにすると、P が大きいと整列度が上がる問題が消え、α が大きい側（0.5・0.6）が論文に近づく。** P=10 と P=30 で整列度がほぼ同じになる（今は P=30 で 0.1 ほど上がる）。α=0.6 は 0.10 で論文と同じ。
  - ただし、留まる割合が P=10 で 29%、P=30 で 53% と、動画（7〜9%、離れた個体）より**ずっと多い**。人気度を遷移の本数で数えるので、長さ 0 の遷移が何本も自分のサイトに重なり、自分のサイトが一番人気になりやすいため。
  - 整列度（移動の平均の長さ / L）は、留まった個体の 0 も平均に入るので、留まるだけで下がる。整列度が下がった分の多くは、そろわなくなったのではなく、動かなくなったことによる。
  - α=0.3 は 0.26〜0.30 で、論文の 0.53 から遠ざかる。密度は変わらない。
- **速度一致なしは、図11 に合わない。** P=10 は整列度 0.1 前後だが、密度 0.32 と低い。P=30 は整列度が 0.3〜0.5 に上がる。動画の図3-6 のような密な塊は、論文1 の条件（N=100・S=50、ω=5）では出なかった（動画は N≈210・S=100 で、ω や α も分からない）。

### 分かったこと・考えられること

- **動画は論文の図とは別の実行で、条件（N・S）も動画ごとに違う。** 数値をそのまま論文と比べることはできない。L=4 と、整列度がどの P でも低いこと、塊が合わさっていく様子は比べられる。
- **動画でも「整列度が低いのに、塊が合わさって大きくなる」状態が出ている。** 今のモデルは、速度一致を移動で取ると塊が合わさらず、θ で取るとそろいすぎる。論文の図11 の「密なのにそろわない」と同じ問題で、著者のコードには、今のモデルにない何かがある可能性が高い。
- **その候補の1つが「その場に留まる」こと。** 動画の P=10 では離れた個体の 7〜9% が留まる。今のモデルは 0%。留まりありにすると P が大きい側と α が大きい側が論文に近づくが、留まる割合が多すぎる。留まり方（例えば自分のサイトの人気度を数えない、自由移動のときだけ留まれる）によって割合が変わるので、動画の 7〜9% に合う読み方を探す余地がある。
- **速度一致なしの動画（図3-6）は「密でそろわない塊」になる。** 論文2 の緑（α 2倍・α=0.5）と同じ見た目。ただし論文1 の条件で速度一致なしにしても、図11 の密度は出なかった。
- **次に試せること：**
  1. 留まり方の読み方を分けて試す（自由移動のときだけ留まれる／自分のサイトの人気度を数えない／1個体1票で数える）。留まる割合を動画の 7〜9% に合わせたうえで、図11 と比べる。
  2. 動画と同じ N≈200・S=100 で、P=10 の「塊が合わさって大きくなる」が出る読み方を探す。塊の合わさり方は、論文の図からは読めない新しい比べ方になる。
  3. 先生に「著者のコードで、長さ 0 の遷移（その場に留まる）は許されていたか」を確認する。
- **注意：** 動画からの取り出しは、描き直し途中のフレームや画質の悪さで誤差がある。P=15・25・図3-6 の留まる割合は信用できない（描き直し途中のフレームを1ステップと数えてしまう）。P=10 の値が一番信用できる。
